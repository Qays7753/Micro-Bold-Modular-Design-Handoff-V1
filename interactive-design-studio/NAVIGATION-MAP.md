# NAVIGATION-MAP — خريطة التنقل داخل الاستوديو (V2 — مراجعة 2026-09-23)

## 1. الغلاف العالمي (GLB-SHELL)

- **الترتيب المعتمد (§11.1):** `مشروعي الآن ← العمل ← المالية ← أدواتي ← السوق` من اليمين في RTL. خمسة تبويبات متساوية، لا زر سادس ولا CTA عائم.
- **الشريط السفلي V2:** خلفية بيضاء مدمجة بالحافة، Divider علوي، **ارتفاع أدنى 70px يتكيف مع تكبير النص** فلا تُقصّ التسميات العربية عند 200% (18 §1.6). الاختيار: أيقونة Fill + تسمية SemiBold + لون Action `#A94630` + **العلامة الرباعية للهوية** (§11.2) تظهر بزاوية الأيقونة — لا اعتماد على اللون وحده. Badge لعدد واضح فقط (العمل: 3).
- **المنطقة العلوية:** بلا اسم صفحة ولا شعار؛ يمينًا زر الحساب (يفتح اللوحة)، يسارًا «التوصيل» و«اسأل Micro» بعلامة رباعية بلون الهوية. **الإجراءان يفتحان مسارات مؤجلة صادقة (GLB-DELIVERY/GLB-ASK) — لا نقر ميت.**
- **لوحة الحساب:** امتداد من الأعلى بزوايا سفلية 24px، فيها حالة اكتمال بيانات المشروع وثلاثة صفوف (حسابي/بيانات المشروع/إعدادات النظام) **تتنقل لمساراتها المؤجلة وتغلق اللوحة**، وتسجيل خروج بحوار قرارين صريحين.

## 2. السحب بين الصفحات (§11.12 — منفذ فعليًا في V2)

- سحب مباشر باللمس/المؤشر **بين الصفحات الرئيسية الخمس فقط** (المستوى 1): المحتوى يتبع الإصبع (يسارًا يحرك يسارًا)، مقاومة خفيفة عند أول/آخر تبويب بلا Loop، يستقر خلال 240–320ms، وحالة الشريط السفلي تتغير بعد الاكتمال.
- **مناطق التعطيل المطبقة:** البطاقات الأفقية (بطاقة SnapshotDeck تدير سحبها بنفسها وتوقف انتشار الحدث)، النماذج والمهام المالية (المستوى 3 مثل OPS-SALE-CREATE بلا سحب)، الطبقات المفتوحة (Sheet/Dialog/Menu/لوحة الحساب)، وأي عنصر بتمرير أفقي داخلي.
- السحب وسيلة إضافية — الضغط على التبويبات وأبدال الوصول (لوحة المفاتيح) باقية. عند Reduced Motion ينتقل فورًا بلا تتبع.

## 4. مستويات العمق

- **مستوى 1** (شريط سفلي + هيدر): OVR-NOW، FIN-OVERVIEW، والجذور المؤجلة (OPS/TOOL/MKT-HOME).
- **مستوى 2** (شريط سفلي، بلا هيدر اسم): OVR-SNAPSHOT-ALL.
- **مستوى 3** (مهمة مركزة: لا شريط سفلي، «إلغاء» يمينًا، إجراء ثابت أسفل): OPS-SALE-CREATE. STUDIO-COMPONENTS تعامَل مثل المستوى 3 لأنها مساحة استوديو لا شاشة منتج.

## 5. أبدال الوصول (§16.4)

كل عناصر التفاعل قابلة للوصول بلوحة المفاتيح: التبويبات والصفوف والأزرار والروابط النصية وأزرار البطاقات وقوائم الفترة، مع Focus مرئي `#305968` (وفوق كتلة الهوية Ink) بحد 2px بلا Glow، وEscape يغلق Sheet/Dialog/Menu/لوحة الحساب.
