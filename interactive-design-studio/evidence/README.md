# دليل الأدلة — evidence/

كل ملف هنا **لقطة فعلية** من تشغيل الاستوديو داخل متصفح Chromium حقيقي (Playwright) بجهاز عرض ×2، أُنتيحت بواسطة سكربت فحص قابل للتكرار بعد `npm run build` + `npm run preview`. اللقطات **دليل مساعد** — ليست بديلًا عن المصدر التفاعلي القابل للتعديل (ZED-START-HERE §7).

## اصطلاح التسمية

- `<screen>_<state>_<width>.png` — حالة الشاشة على عرض محدد (مثل `fin-overview_partial_360.png`).
- `<screen>_<state>_<width>_z150|z200.png` — تكبير نص 150%/200% مع Reflow.
- `<screen>_<state>_<width>_gray.png` — فحص إزالة اللون (Color Removal Test §16.7).
- `fullpage-<screen>_<state>_<width>.png` — الصفحة كاملة (التمرير مأسطر داخل إطار التطبيق) لإظهار التكوين كاملًا.
- `interaction_<what>_360.png` — لقطات تفاعل حقيقي (نقر فعلي مُسجل): لوحة الحساب، Deck، بيان النزاهة، تحقق النموذج، أوراق العميل/الصنف، الحفظ→Echo، قائمة الفترة، تنقل التبويبات.
- `studio-home_360.png` / `ops-home_deferred_360.png` — صفحة الاستوديو وبطاقة التأجيل.

## ماذا يثبت هذا الدليل

1. **320/360/390/412:** لقطات أربع عروض لكل شاشة (افتراضي) + عرض `full` متجاوب.
2. **تكبير 150/200:** `*_z150`, `*_z200` — بلا قصّ أو انفصال المبلغ عن وحدته.
3. **ألوان ثم رمادي:** `*_gray` لكل شاشة افتراضية.
4. **Loading/Error/Offline:** حالات `saving/failure/offline-save/error/offline` لكل شاشة منطبقة.
5. **تميّز التكوين:** مقارنة `fullpage-*` بين المجالات الثلاثة.
6. **عدم ظهور الكاش كربح:** لقطات بيان النزاهة المفتوح `interaction_truth-note-open`.
7. **أثر العملية قبل الحفظ:** `ops-sale-create_impact_360` و`impact-credit`.
8. **الفروق المالية:** `fin-overview_zero/negative/partial/insufficient`.

## حدود هذا الدليل (صريحة)

- فحص متصفح داخل بيئة تنفيذ — **ليس** اختبار Android أصليًا ولا TalkBack ولا مستخدمًا فعليًا (كلها UNVERIFIED في `reports/QA-SUMMARY.md`).
- شريط النظام أعلى الإطار **محاكاة عرض** (حدوده موثقة تحت الإطار) وليس تكاملًا أصليًا.
- Swipe الحقيقي بالإصبع غير مُمثَّل باللقطات (التنقل بين بطاقات الـDeck مثبت بأزرار المؤشر القابلة للنقر).
