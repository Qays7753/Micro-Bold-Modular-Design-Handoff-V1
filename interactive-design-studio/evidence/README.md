# Visual Evidence — Micro V2

الصور داخل `screenshots/` تلتقط الاستوديو V2 في حالاته ومقاسات ممثلة. **المصدر التفاعلي هو المرجع؛ اللقطة لا تعوّض اختبار المتصفح والهاتف.** أزيلت صور التصميم السابق وورقة المقارنة، وكذلك صور 200% التي لم تعد تمثل تخطيط الصفوف بعد إصلاحها.

- `<screen>_<state>_<width>.png`: حالة شاشة في إطار هاتف.
- `*_gray.png`: مراجعة هرمية دون لون.
- `interaction_*.png`: شواهد التفاعل وقت تنفيذ ZAI.
- `fullpage-*.png`: سياق كامل للصفحة أو مساحة المكونات.

سجّل أي لقطة جديدة بتاريخ Commit وطريقة إعادة إنتاجها، وتأكد أن النص والصورة يطابقان الشفرة الحالية. تحقق جديد عند 320/360 و200% مطلوب قبل الادعاء بنجاح إعادة ترتيب الصفوف. راجع `../reports/QA-SUMMARY.md`.
