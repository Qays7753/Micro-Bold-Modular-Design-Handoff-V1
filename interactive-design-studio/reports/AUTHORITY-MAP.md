## 3. قرار Stack — سلطة الاختيار ومبرره

المرجع (`ZED-START-HERE…` §3 و`03-STUDIO-CONSTRUCTION-SPEC.md` «عقد التشغيل والفحص») يخوّل المنفذ اختيار أصغر Stack مستقر قابل للتشغيل والفحص في بيئته، شرط أن يكون مصدر الاستوديو مستقلًا داخل المستودع بـdependencies مثبتة النسخ، ولا يُفرض شكل مكتبة جاهزة على الواجهة.

**الاختيار الموثق:** Vite 5 + React 18 + TypeScript (فقط: `react`، `react-dom`؛ تطوير: `vite`، `@vitejs/plugin-react`، `typescript`، الأنواع). لا مكتبة UI ولا Tailwind ولا مكتبة رسوم — كل مكون يُبنى يدويًا فوق Tokens وفق §§6–16 لأن المرجع يحظر استيراد UI Kit كقاعدة شكلية (§21.2 «الحماية من القوالب»)، والتنقل توجيه Hash مخصص بلا مكتبة Routing لتقليل الاعتماديات. بيئة التنفيذ تضم Node `v24.21.0` ما يجعل هذا الـStack مستقرًا وقابلًا للبناء والفحص المحليين.

**فصل المعاينة عن المصدر:** مصدر الحقيقة هو المستودع؛ تُقدَّم للمالك معاينة تشغيل من نسخة البناء عبر بيئة الجلسة (لوحة المعاينة) بوصفها وسيلة مراجعة مؤقتة موثقة حدودها في `reports/DELIVERY-REPORT.md`، ولا تحل محل المصدر القابل للتعديل.
