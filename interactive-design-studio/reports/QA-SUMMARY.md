## 3. عيوب التنفيذ (عولجت) وملاحظات P3 المفتوحة

- عولج أثناء الفحص: تداخل تلميح الـDeck مع زر التالي (P2 → زال)، وحجب الشريط الثابت للتمرير (P3 → زال). التفصيل في VISUAL-PROOF-REVIEW.
- P3 مفتوحة موثقة (لا تؤثر على الفهم/الثقة/الوصول): سهم تقدم RTL قد يُقرأ ملتبسًا لدى بعض المراجعين (قرار معتمد، للنقاش)، وسم Fixtures الظاهر داخل قسم الأثر (شرط صدق، للنقاش)، شريط النظام المحاكى تمثيل لا تكامل أصلي (موثّق تحت الإطار).

## 4. قابلية التكرار

`npm install && npm run build` من مصدر المستودع يعيد النتيجة دون أي اعتماد على جلسة المنفذ (الاعتماديات مثبتة النسخ). سكربتات الفحص نفسها كانت تعمل من خارج المستودع ولا تُسلَّم ضمنه؛ خطوات إعادة الفحص اليدوي موثقة في README.
