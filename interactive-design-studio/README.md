# Micro Interactive Design Reference Studio

هذا المجلد هو مساحة التنفيذ المستقلة لتصميم Micro الجديد. لا يحتوي على كود تطبيق Micro الإنتاجي ولا يغيره.

## الهدف

تحويل حزمة القرارات والـHandoff الموجودة في جذر المستودع إلى استوديو تفاعلي قابل للتشغيل والمراجعة على الهاتف، مع Tokens وComponents وشاشات وحالات وأدلة.

## بوابة التنفيذ الحالية

يجب أن يبدأ المنفذ بالبنية الأساسية ثم ينفذ هذه العينات الثلاث فقط قبل التوسع:

- `OVR-NOW`
- `OPS-SALE-CREATE`
- `FIN-OVERVIEW`

تظل بقية الشاشات مؤجلة إلى مراجعة المالك للعينات الثلاث.

## بنية المجلد

| المسار | الغرض |
|---|---|
| `src/` | مصدر الاستوديو والمكونات والشاشات |
| `public/` | ملفات تشغيل عامة غير سرية |
| `fixtures/` | بيانات اختبار موسومة وليست بيانات مالية حقيقية |
| `assets/` | أصول ومصادر وتراخيص |
| `evidence/` | لقطات وأدلة تشغيل مساعدة |
| `reports/` | تقارير Preflight وQA والتسليم والفجوات |

## الحدود

- لا Figma إلزامي في هذا المسار.
- لا تعتبر HTML ثابتًا أو Screenshot بديلًا؛ المطلوب تطبيق تفاعلي مصدره قابل للتعديل.
- لا تضع أي Secret أو Access Token أو بيانات اعتماد في هذا المجلد.
- لا تستخدم هذا المجلد لتعديل Micro أو نقل قراراته المالية.

## التشغيل

يضيف المنفذ أمر التشغيل الفعلي بعد اختيار الـStack، ثم يوثقه هنا مع أوامر التحقق وروابط المعاينة المحلية.

## حالة المجلد

`Prepared for Zed execution` — لم يُبنَ الاستوديو بعد.
