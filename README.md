# Micro — Final Visual Design Standard V2

**مرجع التصميم الحالي والوحيد للتنفيذ المرئي.** اعتمد المالك اتجاه V2 المعروض؛ اعتمد `#D97757` لون هوية قائدًا. مستودع التصميم مستقل عن تطبيق Micro الإنتاجي.

## ابدأ بهذا الترتيب

1. [قواعد العمل](AGENTS.md) وحدودها.
2. [قرارات التصميم الكاملة](DESIGN-DECISIONS-V2.md) و[معيار اللون](COLOR-STANDARD-V2.md).
3. [معايير نقل التصميم إلى Micro](TRANSFER-READINESS-V2.md): ابدأ بالتوكنز والمكونات المشتركة ثم راجع أثرها على الشاشات، ولا تنسخ نموذج شاشة على كل النظام.
4. [استوديو التصميم التفاعلي](interactive-design-studio/README.md) ومصدره؛ `src/foundations/` للتوكنز الحية و`DESIGN-SYSTEM.md` للمبادئ المنفذة و`COMPONENT-CATALOG.md` لعقود المكونات.
5. [جرد الشاشات](SCREEN-COVERAGE-V2.csv)، [أمثلة الضغط الأردنية](JORDANIAN-FIXTURES.md)، [خريطة التصميم إلى التطوير](interactive-design-studio/DESIGN-TO-DEVELOPMENT.md)، [QA](interactive-design-studio/reports/QA-SUMMARY.md)، [القضايا المفتوحة](interactive-design-studio/reports/OPEN-ISSUES.md).

## النطاق الحقيقي

الاستوديو يحتوي ثلاث شاشات منتج (21 حالة) ونمط «كل البطاقات» ومكتبة مكونات؛ `STUDIO-COMPONENTS` وأدوات الحالة والبيانات `fixtures/` أدوات مراجعة فقط. لم تُصمم جميع شاشات Micro، ولا تُنسخ أمثلة أثر البيع كمنطق مالي. لا Dark Mode. الأرقام `0–9` والعملة `د.أ` وRTL عربي. التصميم القديم ليس مصدر شكل.

## طريقة الفحص

من `interactive-design-studio/`: شغّل `npm ci` ثم `npm run dev`، و`npm run build` للتحقق من البناء. متصفح/هاتف 320 و360 و390 و412 وتكبير 150% و200% يجب فحصهما على تنفيذ Micro؛ الصور الحالية أدلة للنسخة المعروضة قبل إصلاح تخطيط الصفوف عند 200% وليست اختبارًا جديدًا للإصلاح. رابط معاينة GitHub Pages ليس جاهزًا بسبب صلاحية إعداد Pages؛ البناء قابل للتنزيل من GitHub Actions.
