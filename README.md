# Micro — Visual Design Execution Handoff

هذا المستودع يحتوي ملفات تسليم التصميم المرئي الجديد لـMicro، بصيغ Markdown وCSV قابلة للقراءة مباشرة. لا يحتوي على ملف Figma منجز أو تطبيق Micro الإنتاجي.

## ابدأ من هنا

1. اقرأ [ملف البداية](00-START-HERE.md) و[مرجع القرارات المعتمدة](MICRO-VISUAL-DESIGN-DECISIONS-V1.md) كاملين.
2. اقرأ [أمر التنفيذ](01-MASTER-EXECUTION-PROMPT.md) و[مراحل التنفيذ وبوابات الدليل](16-EXECUTION-STAGES-AND-PROOF-GATES.md) ثم بقية الملفات المرقمة قبل البدء في تصميم الشاشات.
3. تأكد من امتلاك قدرة فعلية على إنشاء ملف Figma قابل للتحرير وتسليمه لصاحب المشروع. لا تصف HTML أو الصور بأنها بديل مكافئ.
4. هذا المستودع هو وجهة العمل والتسليم التي حددها المالك للمصمم المنفذ: أنجز Preflight، ثم Foundations مرشحة وثلاث عينات Figma مختلفة قبل التوسع، وبعد إنجاز العمل ارفع مخرجات التصميم ووثائقها هنا في مسارات واضحة، مع روابط Figma والأدلة الفعلية والتقرير النهائي. لا ترفع إلى مستودع آخر أو تعدل تطبيق Micro الإنتاجي.

المرجع الأعلى عند التعارض هو `MICRO-VISUAL-DESIGN-DECISIONS-V1.md`. ملفات التصميم القديمة في تاريخ Git ليست مرجعًا بصريًا أو تعليمات سارية. الألوان والقرارات المعتمدة لا يعاد فتحها بسبب تقرير قديم؛ الجودة البصرية لا تثبت إلا بعينات Figma ومراجعتها. الحالات التي لم تُختبر تُسجل `UNVERIFIED`، ولا يُدعى اعتماد المالك قبل حدوثه.
