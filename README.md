# Micro — مرجع التصميم المرئي V2

**الحالة 2026-09-23:** اعتمد مالك Micro اتجاه V2 المرئي المعروض في استوديو ZAI. المصدر يتيح **بدء نقل تدريجي** إلى تطبيق Micro؛ لم تُبنَ بقية شاشات المنتج ولم يُختبر تطبيق Micro بعد النقل. [اقرأ قرار الجاهزية وحدوده](20-V2-DESIGN-TRANSFER-READINESS-2026-09-23.md) أولًا.

## افتح ما تم تصميمه

1. [الاستوديو التفاعلي وتعليمات التشغيل](interactive-design-studio/README.md) — `npm ci` ثم `npm run dev` من مجلده؛ افتح العنوان المحلي الذي يظهر في الطرفية.
2. جرّب `OVR-NOW` (مشروعي الآن) و`OPS-SALE-CREATE` (تسجيل بيع) و`FIN-OVERVIEW` (المالية)، ثم `OVR-SNAPSHOT-ALL` (عرض كل البطاقات). `STUDIO-COMPONENTS` مساحة فحص مكونات وليست شاشة منتج.
3. [خريطة تسليم التصميم إلى التطوير](interactive-design-studio/DESIGN-TO-DEVELOPMENT.md) و[سجل تغطية V2](interactive-design-studio/reports/REVISION-COVERAGE-LEDGER.md) يحددان ما بُني وما بقي مؤجلًا.

## حدود مهمة

هذا المستودع مستقل عن تطبيق Micro الإنتاجي. نموذج البيع والحركات ونتائج الربح فيه Fixtures للعرض؛ لا تنسخها كمنطق مالي. لون الهوية `#D97757`، واجهة عربية RTL، أرقام `0–9` وعملة `د.أ`، ولا وضع ليلي في هذه المرحلة. أُصلحت مشكلتا قراءة الصفوف عند تكبير 200% والمبالغ المضمّنة في صف العملية الجزئية، والبناء ناجح؛ إعادة فحص العرض على هاتف حقيقي مطلوبة أثناء النقل. رابط معاينة GitHub Pages لم يتوفر بعد لأن إعداد Pages فشل بصلاحيات التكامل، والمصدر يعمل محليًا.
