# Micro — Visual Design Execution Handoff

هذا المستودع يحتوي ملفات تسليم التصميم المرئي الجديد لـMicro، بصيغ Markdown وCSV قابلة للقراءة مباشرة. لا يحتوي حتى الآن على استوديو منجز أو معاينة حية أو تطبيق Micro الإنتاجي.

## ابدأ من هنا

1. اقرأ [ملف البداية](00-START-HERE.md) و[مرجع القرارات المعتمدة](MICRO-VISUAL-DESIGN-DECISIONS-V1.md) كاملين.
2. اقرأ [أمر التنفيذ](01-MASTER-EXECUTION-PROMPT.md) و[مراحل التنفيذ وبوابات الدليل](16-EXECUTION-STAGES-AND-PROOF-GATES.md) ثم بقية الملفات المرقمة قبل البدء في تصميم الشاشات.
3. تأكد من القدرة على إنتاج استوديو مستقل بمصدر قابل للتعديل ومعاينة يمكن للمالك فتحها من هاتفه. Figma اختياري؛ HTML ثابت والصور وحدها لا تكفي.
4. هذا المستودع هو وجهة العمل والتسليم التي حددها المالك للمصمم المنفذ: أنجز Preflight، ثم Foundations مرشحة وثلاث شاشات تفاعلية مختلفة قبل التوسع، وبعد الإنجاز ارفع مصدر الاستوديو وملفاته ووثائقه هنا، مع رابط معاينة قابل للفتح وأدلة فعلية والتقرير النهائي. لا تنشر على خدمة إضافية بلا تفويض. لا ترفع إلى مستودع آخر أو تعدل تطبيق Micro الإنتاجي.

المرجع الأعلى عند التعارض هو `MICRO-VISUAL-DESIGN-DECISIONS-V1.md`. ملفات التصميم القديمة في تاريخ Git ليست مرجعًا بصريًا أو تعليمات سارية. الألوان والقرارات المعتمدة لا يعاد فتحها بسبب تقرير قديم؛ الجودة البصرية والتفاعل يثبتان بعينات الاستوديو ومراجعتها على الهاتف. الحالات التي لم تُختبر تُسجل `UNVERIFIED`، ولا يُدعى اعتماد المالك قبل حدوثه.
