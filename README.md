# Micro — Visual Design Execution Handoff

هذا المستودع يحتوي ملفات تسليم التصميم المرئي الجديد لـMicro، واستوديو تصميم تفاعليًا مستقلًا داخل `interactive-design-studio/` بوصفه نسخة مرشحة للمراجعة. لا يحتوي على تطبيق Micro الإنتاجي، ولم تُعتمد مراجعة الألوان الجديدة داخل الاستوديو بعد.

## ابدأ من هنا

1. اقرأ [ملف البداية](00-START-HERE.md) و[مرجع القرارات المعتمدة](MICRO-VISUAL-DESIGN-DECISIONS-V1.md) كاملين.
2. اقرأ [أمر التنفيذ](01-MASTER-EXECUTION-PROMPT.md) و[مراحل التنفيذ وبوابات الدليل](16-EXECUTION-STAGES-AND-PROOF-GATES.md) ثم بقية الملفات المرقمة قبل البدء في تصميم الشاشات.
3. تأكد من القدرة على إنتاج استوديو مستقل بمصدر قابل للتعديل ومعاينة يمكن للمالك فتحها من هاتفه. Figma اختياري؛ HTML ثابت والصور وحدها لا تكفي.
4. هذا المستودع هو وجهة العمل والتسليم التي حددها المالك للمصمم المنفذ: أنجز Preflight، ثم Foundations مرشحة وثلاث شاشات تفاعلية مختلفة قبل التوسع، وبعد الإنجاز ارفع مصدر الاستوديو وملفاته ووثائقه هنا، مع رابط معاينة قابل للفتح وأدلة فعلية والتقرير النهائي. لا تنشر على خدمة إضافية بلا تفويض. لا ترفع إلى مستودع آخر أو تعدل تطبيق Micro الإنتاجي.

المرجع الأعلى للألوان اعتبارًا من 2026-09-23 هو `17-COLOR-DECISION-2026-09-23.md`، وأمر تصحيح الاستوديو الحالي هو `18-ZAI-STUDIO-REVISION-BRIEF-2026-09-23.md`، وجرد التغطية المطلوب لكل المكوّنات والحالات المنفذة هو `19-STUDIO-COMPLETE-COVERAGE-GATE-2026-09-23.md`. بقية القرارات في `MICRO-VISUAL-DESIGN-DECISIONS-V1.md`. Indigo/Citrus وتقارير التنفيذ ولقطاته وصف للإصدار السابق حتى يعيد ZAI بناءها والتحقق منها. ملفات التصميم القديمة في تاريخ Git ليست مرجعًا بصريًا أو تعليمات سارية. الجودة البصرية والتفاعل يثبتان بعينات الاستوديو ومراجعتها على الهاتف. الحالات التي لم تُختبر تُسجل `UNVERIFIED`، ولا يُدعى اعتماد المالك قبل حدوثه.
